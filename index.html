Logic Acquired

First Conditional

We use the First Conditional to talk about a real possibility in the future.

Code Structure:

If + Present Simple , WILL + Verb

"If I die, she will die too."

> Condition (Now) -> Consequence (Future)

Logic Acquired

Orders & Conditions

In a negotiation, we often use an Order (Imperative) connected to a Consequence.

Code Structure:

Order + OR / AND + WILL + Verb

"Don't come closer or I will jump!" > (Threat)

"Drop the gun and I will help you." > (Offer)
